## About Bonney Watson Quote Tool

Bonney Watson Quote Tool is a quote generator written in HTML and meant to be used inside a web browser. Everything revolves around a plain, easy-to-follow interface that lets you build quotes without installing a large application stack or any special runtime.

If you need a small, quote-focused utility that you can simply open from the web, this project fits that role. The codebase stays deliberately simple, so loading the page, checking the output, and working with the generated quote takes very little effort.
